# AURORA — Superhuman-inspired mail shell

AURORA uses an original interface inspired by fast, minimalist productivity mail clients. It does not copy Superhuman branding, assets, proprietary layouts, or source code.

## Included

- Three-pane desktop-inspired workspace
- Compact mobile reader mode
- Fast search command palette
- Inbox/unread hierarchy and virtualized lists
- 120 Hz-compatible iOS configuration
- Native Reanimated dependency
- Dark, restrained typography and color system

## Typography

The app uses the platform-native system font stack. This preserves legibility and performance. If a licensed Superhuman-style commercial font is available to you, integrate it only through an app-owned font license; it should not be copied from another app or website.
